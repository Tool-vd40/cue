# Cue (Суфлёр)

Суфлёр для созвонов: тезисы поверх всех окон. Тебе видно, тем, кому
показываешь экран, — нет.

[English](README.md)

Панель помечена `NSWindow.sharingType = .none`: macOS вырезает такие окна из
захвата экрана. Zoom, Meet, Teams, запись QuickTime и системный снимок идут
через этот захват, поэтому панель в них не попадает.

## Установка

Скачай `Cue.dmg` со страницы [Releases](../../releases/latest) и перетащи Cue в «Программы».

Приложение подписано своей подписью, без нотаризации Apple, поэтому первый
запуск macOS блокирует. На macOS 15 и новее: открой Cue один раз, затем
Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
На macOS 13–14: правой кнопкой по Cue → «Открыть» → «Открыть». Или в Терминале:

    xattr -dr com.apple.quarantine /Applications/Cue.app

Значка в Dock нет — Cue живёт в строке меню. Нужна macOS 13 или новее.
Язык интерфейса — по языку системы (русский или английский).

## Обновления

При запуске Cue проверяет GitHub Releases и предлагает поставить новую
версию. Вручную: меню-бар → «Проверить обновления…».

## Хоткеи

| | |
|---|---|
| ⌃⌥P | показать / скрыть панель |
| ⌃⌥V | вставить тезисы из буфера |
| ⌃⌥↑ ⌃⌥↓ | листать |
| ⌃⌥пробел | автопрокрутка |
| ⌃⌥1 … ⌃⌥9 | переключить открытый файл |

Если сочетание занято другим приложением, Cue напишет об этом первой строкой
в меню.

Колесо мыши крутит текст, панель таскается за любое место и тянется за края.
Наведи мышь — появятся кнопки. Текст правится в меню-баре → «Править текст…».

## Несколько файлов

«Загрузить файлы…» берёт хоть все сразу: показ, вопросы, цифры. Вкладки видны
при наведении, переключение щелчком или ⌃⌥1…9. У каждого файла своя позиция
прокрутки.

## Прокрутка под голос

Кнопка с микрофоном: текст едет, пока говоришь, и стоит, пока молчишь.
Распознавания речи нет. Разрешение на микрофон спрашивается при включении.

## Сборка и релиз

    ./scripts/make-dmg.sh             # dist/Cue.app, Cue.dmg, Cue.zip
    .build/release/Cue --selftest     # проверка логики
    git tag v1.1.0 && git push origin v1.1.0   # CI соберёт и выложит релиз
