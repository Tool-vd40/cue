# Cue (Суфлёр)

Суфлёр для созвонов: тезисы поверх всех окон. Тебе видно, тем, кому
показываешь экран, — нет.

**[⬇ Скачать Cue для macOS](https://github.com/Tool-vd40/cue/releases/latest/download/Cue.dmg)** · macOS 13+ · [все версии](../../releases) · [English](README.md)

Панель помечена `NSWindow.sharingType = .none`: macOS вырезает такие окна из
захвата экрана. Zoom, Meet, Teams, запись QuickTime и системный снимок идут
через этот захват, поэтому панель в них не попадает.

## Установка

1. [Скачай установщик Cue.dmg](https://github.com/Tool-vd40/cue/releases/latest/download/Cue.dmg).
2. Открой его и перетащи **Cue** в **Программы**.
3. Запусти Cue из «Программ».

Значка в Dock нет — Cue живёт в строке меню вверху экрана (значок в виде
строк текста). Нужна macOS 13 или новее. Язык интерфейса — по языку системы
(русский или английский).

### «Apple не удалось подтвердить, что Cue не содержит вредоносного ПО»

При первом запуске macOS покажет это предупреждение. Так и должно быть:
код Cue открыт, но приложение не проходило нотаризацию Apple (для неё нужен
платный аккаунт разработчика). macOS пишет так про любое приложение, скачанное
из интернета без нотаризации. Разрешить нужно один раз.

**macOS 15 Sequoia и новее**

1. В предупреждении нажми **«Готово»** (не «Переместить в Корзину»).
2. Открой **Системные настройки → Конфиденциальность и безопасность**,
   прокрути вниз.
3. Рядом с «Программа Cue заблокирована…» нажми **«Всё равно открыть»**.
4. Подтверди паролем или Touch ID и ещё раз нажми **«Всё равно открыть»**.

**macOS 13 Ventura и 14 Sonoma**

1. В Finder открой **Программы**.
2. Правой кнопкой (или с Control) по **Cue** → **«Открыть»**.
3. В окне нажми **«Открыть»**.

**Любая версия, через Терминал**

    xattr -dr com.apple.quarantine /Applications/Cue.app

Команда снимает пометку «скачано из интернета», из-за которой и появляется
предупреждение.

Дальше Cue открывается как обычно, а обновления из меню ставятся без
предупреждения.

## Обновления

При запуске Cue проверяет GitHub Releases и предлагает поставить новую
версию. Вручную: меню-бар → «Проверить обновления…».

## Хоткеи

| | |
|---|---|
| ⌃⌥P | показать / скрыть панель |
| ⌃⌥V | вставить тезисы из буфера |
| ⌃⌥↑ ⌃⌥↓ | листать |
| ⌃⌥пробел | автопрокрутка |
| ⌃⌥1 … ⌃⌥9 | переключить открытый файл |

Если сочетание занято другим приложением, Cue напишет об этом первой строкой
в меню.

Колесо мыши крутит текст, панель таскается за любое место и тянется за края.
Наведи мышь — появятся кнопки. Текст правится в меню-баре → «Править текст…».

## Несколько файлов

«Загрузить файлы…» берёт хоть все сразу: показ, вопросы, цифры. Вкладки видны
при наведении, переключение щелчком или ⌃⌥1…9. У каждого файла своя позиция
прокрутки.

## Прокрутка под голос

Кнопка с микрофоном: текст едет, пока говоришь, и стоит, пока молчишь.
Распознавания речи нет. Разрешение на микрофон спрашивается при включении.

## Сборка и релиз

    ./scripts/make-dmg.sh             # dist/Cue.app, Cue.dmg, Cue.zip
    .build/release/Cue --selftest     # проверка логики
